# 🧮 Calculadora de Partidas Rankeadas

Este projeto foi desenvolvido como parte de um desafio da **DIO**.  
O objetivo é calcular o saldo de vitórias de um jogador e determinar seu nível de acordo com a quantidade de vitórias.
